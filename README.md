# إمساكية رمضان 1448هـ — النادي البحري للنيابة الإدارية
تطبيق ويب ثابت (PWA) يعمل دون إنترنت. لا يحتاج أي خادم.

- `site/` الملفات المصدرية (index.html, styles.css, app.js, data.js, sw.js, manifest, fonts, icons, logo).
- `build.py` يبني `dist/` (ملف HTML واحد بالخطوط والأكواد مضمّنة) للنشر على أي استضافة ثابتة (Vercel / Netlify / GitHub Pages).
- `gen/calc.js` يحسب المواقيت (adhan-js، طريقة الهيئة المصرية العامة للمساحة، الإمساك = الفجر − 10 دقائق، تقريب الفجر للأسفل والمغرب للأعلى بما يطابق الإمساكيات المنشورة).
- عدد أيام الشهر في `app.js` → `CFG.ramadanDays` (افتراضيًا 29 حسب الحساب الفلكي، يُغيَّر إلى 30 عند الحاجة).
- الشعار: استبدل `site/logo.png` و`site/icons/*` بالشعار الرسمي، واضبط `CFG.assets.callig` لصورة مخطوطة «كل عام وأنتم بخير».
- للمعاينة بتاريخ معيّن: أضف `?now=2027-02-10T15:30:00+02:00` للرابط.
